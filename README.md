# LocalASO releases

Downloads for **LocalASO**, the local App Store keyword research and ASO app for macOS.

- Website and license: https://localaso.com
- Download page: https://localaso.com/download
- Latest release: https://github.com/gianmaurice/localaso-releases/releases/latest

| Mac | File |
|---|---|
| Apple Silicon (M1 or newer) | `LocalASO-<version>-arm64.dmg` |
| Intel | `LocalASO-<version>-x64.dmg` |

The app is signed with an Apple Developer ID and notarized by Apple. To verify a download, compare
`shasum -a 256 <file>.dmg` with the matching line in `SHA256SUMS` attached to each release.

This repository contains release binaries only. LocalASO is commercial software; a license key is required
(see https://localaso.com/terms and https://localaso.com/eula). Support: support@localaso.com
